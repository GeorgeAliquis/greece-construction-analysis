# Greece Construction Analysis

🚧 **Status: Under Development**

This project aims to explore and analyze datasets from Greece published by the Hellenic Statistical Authority (ELSTAT / ΕΛΣΤΑΤ).

The analysis will focus on **new buildings, number of floors, building volume, and surface area**, broken down by region (*Περιφέρεια*) and regional unit (*Περιφερειακή Ενότητα*).

The goal is to uncover regional patterns, identify trends in construction activity, and present meaningful insights through data analysis and visualization.

More updates and findings will be added as the project develops.
